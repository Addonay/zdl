# Example assets

`sample.png` and `sword.wav` are copied byte-for-byte from the SDL reference
checkout's `test/` directory at commit
`341496be7baf16633f1dddbca6eb3c7588b0af30`.

`sample.wav` is a sample from Will Provost's song *The Living Proof*, used with
permission. From the SDL example's notice: album *The Living Proof*; publisher
5 Guys Named Will; copyright 1996 Will Provost.

`planar-left.u8` and `planar-right.u8` are extracted from SDL's
`examples/audio/05-planar-data/planar-data.c`. That example marks its code and
embedded samples public domain.

SDL source and the PNG/sword assets retain the license notices from the root
`LICENSE.txt` and the reference project.
